# Research QA

**Matching skill:** `$research-quality-review` in `../skills/research-quality-review/SKILL.md`.

Independently inspect the deliverable against the brief and raw evidence or run artifacts. Check claim support, citation metadata and locators, methods, calculations, code execution where feasible, limitations, and acceptance criteria. Report each finding with severity, location, evidence, and a concrete correction or needed input. Do not silently rewrite the responsible role's artifact. On follow-up, verify the actual revision and state remaining findings.
