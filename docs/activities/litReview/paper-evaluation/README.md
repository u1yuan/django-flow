# Paper-evaluation workflow

Track: shared. This is a reproducible rubric for evaluating research papers. Every criterion traces to a location in one of two source papers:

- **Paper A:** Effendy et al. (2025), *A Quality Assurance Framework for Model Building in Machine Learning Workflow – A Research Plan*, ICSIM '25, doi:10.1145/3725899.3725909. **A research plan with no results.** Its framework is not validated.
- **Paper B:** Remmel, Paech, Engwer, & Bastian (2014), *A Case Study on a Quality Assurance Process for a Scientific Framework*, CiSE 16(3):58–66, doi:10.1109/MCSE.2014.57.

No PDF or full text is stored here, because auto-sync pushes every file to GitHub. Only short quotes (25 words or fewer) with locators are kept.

## Files

| File | Role |
| --- | --- |
| `source-trace.md` | URLs, access dates, access level, and locator limits for A and B |
| `concept-extraction.md` | QA concepts from A and B with locations, and which candidate seeds were confirmed or discarded |
| `rubric.csv` | 15 criteria, each scored 0–2 (`rubric_version` 1.0.0) |
| `desk-check-checklist.md` | Single-reviewer pass to complete before scoring |
| `templates/evaluation-template.md` | Per-paper evaluation form (DOI, access level, evidence location and quote for each criterion) |
| `evaluations/` | Completed evaluation forms. The pilot has `A-effendy2025_ai-draft.md` and `B-remmel2014_ai-draft.md` |
| `scores/scores.csv` | One row per paper, reviewer, and criterion |
| `scores/summary.csv` | Generated by the script. Do not edit by hand |
| `scripts/score_papers.py` | Validator, totals, and Cohen's kappa (standard library only) |
| `scripts/tests/` | Unit tests. Fixtures are named and headed `SYNTHETIC` |
| `AI_INTERACTION_LOG.md` | Prompts, outputs, and the human verification list |

## Run order

1. **Retrieve.** Get the paper, then record the URL, access date, and access level in the evaluation form. If only the abstract is available, say so. The abstract supports only what it states.
2. **Desk-check.** Work through `desk-check-checklist.md` and record the results in the form.
3. **Score.** Copy `templates/evaluation-template.md` to `evaluations/<paper_id>_<reviewer>.md`. Score every criterion using the anchors in `rubric.csv`, and fill in the evidence location and quote for each.
4. **Enter.** Add 15 rows per paper per reviewer to `scores/scores.csv`. The script rejects incomplete sheets.
5. **Run the script and tests** from this folder:

   ```text
   python -B scripts/score_papers.py
   python -B -m unittest discover -s scripts/tests -v
   ```

   `-B` stops Python writing `__pycache__`; `.gitignore` here also excludes it. A failing run is a failed result: fix the input and rerun, and do not edit `summary.csv` by hand.

## Inputs and outputs

- **Inputs:** `rubric.csv` and `scores/scores.csv`. The script fails on a header that does not match exactly.
- **Validation** (exit code 1, summary not written) catches:
  - unknown `criterion_id`
  - a score that is not 0, 1, 2, or NA
  - an empty `evidence_location`
  - NA on a criterion whose guiding question lacks "NA allowed if"
  - NA without a note
  - a `rubric_version` that does not match the rubric
  - duplicate rows
  - one `paper_id` with two DOIs
  - a paper/reviewer sheet missing a criterion
- **Outputs:** a report on stdout and `scores/summary.csv`.
  - `total` rows: points, max points, and NA count per paper and reviewer. NA criteria are removed from `max_points`.
  - `kappa` rows: unweighted Cohen's kappa per criterion for each pair of reviewers who scored the same papers. The labels 0, 1, 2, and NA are each treated as a category. Kappa is computed across the papers both reviewers scored.
- **Determinism:** rows are sorted, numbers use 4 decimal places, and nothing depends on time or randomness.
- **Kappa status values:**
  - `undefined`: expected agreement is 1, so kappa is 0/0.
  - `unstable`: the reviewers share fewer than two papers.

  With one shared paper per criterion, kappa is not meaningful. Agreement needs several papers.

## How a new reviewer reproduces a score

1. Use the same `rubric_version` (1.0.0). If anchors change, bump the version and rescore. Never mix versions in one comparison.
2. Retrieve the paper from the copy listed in `source-trace.md` or in the evaluation form. Use the same locator scheme.
3. Complete the desk-check, then score every criterion **without reading the existing evaluations**, so the second set of scores stays independent.
4. Add rows under your own `reviewer` name, then run the script. The kappa rows for your pair with `ai-draft` show agreement.
5. To reproduce a single score, open the recorded evidence location, read the quote in context, and apply the anchor's minimum condition. Every anchor states an observable condition, so two reviewers reading the same passage should reach the same score. If they do not, the anchor needs revision.

## Support levels

- **full-text:** the concept is stated at the cited location in the full text, and the criterion turns it into a question.
- **adapted:** my own extension of a source concept to a scope the source does not address.
- **abstract-only:** the concept is supported only by an abstract. Not used, because full text was obtained for both papers.

The score anchors (0/1/2) are my own operational wording in every case, whatever the support level. They are not quoted from A or B.

| Support level | Criteria |
| --- | --- |
| full-text | C02–C13 (12) |
| adapted | C01, C14, C15 (3) |
| abstract-only | none (0) |

## Pilot (reviewer `ai-draft`, 2026-10-31)

| Paper | Total |
| --- | --- |
| A-effendy2025 | 12/30 |
| B-remmel2014 | 24/30 |

**Interpretation limit.** A and B are the sources of the rubric, so this pilot checks that the rubric can be applied consistently. It is not evidence that the rubric is valid. B scores high partly because most criteria were derived from B. A scores low partly because it is a plan: several criteria reward reported evidence that a plan cannot yet have. The totals are not a quality ranking of the two papers. Kappa cannot be computed until a second human reviewer scores both papers independently.
