## Counter status and required adapters for current candidates

[`data-target-count.py`](data-target-count.py) currently implements the initial RECON/BDG2/London normalized schemas only. The current COFACTOR and iFlex candidates need new source-specific adapters and counting paths; those have not been implemented or run. Do not treat the existing BDG2 or London modes as satisfying current gates. The counter expects uncompressed UTF-8 CSVs, preserves inputs, and reports aggregate/per-entity counts. Keep raw files immutable. Record source URL, version, hashes, conversion steps and row counts. Do not run counts before validating interval semantics, timezone and DST.

1. RECON: derive `entity,timestamp,cumulative_kwh`, sorted globally by entity then timestamp; retain 2020+ only, verify timestamps are interval ends and converted to one unambiguous time basis. Run the existing `recon` mode on a complete derived export. The count requires a complete preceding day for the one-day lag. A reading reset invalidates its crossing interval.
2. COFACTOR: identify imported-electricity meters in the building files; retain only timestamped observations on/after 2020-01-01. A source parser and counting adapter must be implemented and checked against file metadata before the gate can run.
3. iFlex: identify the documented household consumption and price-signal fields; retain only matched 2020+ records. A source parser and target-price join/count adapter must be implemented and checked against the Zenodo release documentation before the gate can run.

Run the counter on the **complete** source scope, record its JSON output and SHA-256 hashes, then independently cross-check totals and exclusions. A small permitted sample can validate parsing only. The gate stays pending until full eligible counts and coverage by household or meter are available. Forecast evaluation then needs chronological train/validation/test periods; assess errors and alert performance per household/meter, with thresholds learned only from training periods. Philippine accuracy needs a separately permitted and comparable local test series.
