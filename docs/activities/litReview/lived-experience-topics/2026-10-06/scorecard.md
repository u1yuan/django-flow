# Scorecard: lived-experience idea pool

Compiled: 6 October 2026. Scores are screening judgments for which ideas to check next. They are not measurements, publication decisions, or dataset audits.

Source: `idea-pool.md`. Each score is an integer from 1 (weak) to 5 (strong).

| Criterion | Question the score answers |
| --- | --- |
| Fun | Would a student group enjoy defending this for a year? |
| Publishability | Is there a plausible gap, baseline, and venue type? Prior-work crowding lowers this. |
| Marketability | Is there a named kind of user (agency, commuter, student, shopper)? Interest is not confirmed. |
| Data | Is there a plausible path to at least 10,000 records of the stated unit? |
| Ethics | Higher means lower risk. Public aggregates score 5. Personal data, accusations, or platform bans score lower. |
| Scope | Can one thesis term finish it, including a baseline and a held-out test? |

Gate: an idea is dropped when its own record unit has no plausible path to 10,000 records. Dropped ideas are not ranked.
